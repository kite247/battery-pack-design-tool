Battery Pack Designer

Interactive 3D tool for designing battery packs with 21700 cells

Navigation

  • Left-click + drag to rotate the view
  • Scroll wheel to zoom in/out
  • Right-click + drag on empty space to pan

Pack Layout

  • Use the top-left panel to choose a layout (regular grid, staggered X, or staggered Y) and set the number of cells

Cell Options

  • Right-click a cell to open its context menu
  • Rotate Polarity flips a cell 180° so its positive and negative ends swap

Nickel Strips

  • Right-click a cell and choose Connect Strip (Top) or Connect Strip (Bottom)
  • Hover over another cell to preview the connection — all cells in the rectangular area between source and target are highlighted
  • Click the target cell to place strips connecting every adjacent pair in both X and Y directions
  • Press Esc or right-click to cancel
  • Right-click an existing strip to remove it

Pack Terminals

  • Right-click a nickel strip and select Set as Pack + Terminal or Set as Pack - Terminal
  • The strip changes color (red for +, blue for -) with a floating label
  • You can clear a terminal assignment from the same menu

Analysis

  • The left panel shows live stats: cell count, connections, terminal status, and estimated specs
  • Once all cells are connected and both terminals are assigned, the pack configuration is detected (e.g. 4S3P) with voltage and capacity

Sharing

  • Click the Share button to get a link that encodes your entire design in the URL — anyone who opens it sees the same pack
